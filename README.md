# Student and Course Management System

This is a simple Java-based console mini project that demonstrates core Object-Oriented Programming (OOP) concepts. The system allows user to input and display student and course details including graduate students and grade calculation.

## 🧠 Concepts Used
- Class Design & Inheritance
- Constructor & Method Overloading
- Interfaces and Abstract Classes
- Static Variables and Methods

## 📁 Files Included
- `StudentCourseManagement.java` – Main program file
- `Student_Course_Management_Report.pdf` – Detailed report of the project
- `Student_Management_Output.jpg` – Output console screenshot

## 🚀 How to Run
Just run the Java file in any IDE (like BlueJ, Eclipse, IntelliJ) or using a terminal/command line:
```bash
javac StudentCourseManagement.java
java StudentCourseManagement
